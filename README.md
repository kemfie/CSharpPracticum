## Инструкция по запуску
1. Склонируйте репозиторий.
2. Откройте решение `Visual Studio.slnx` в Visual Studio.
3. Нажмите `F5` (или "Пуск"), чтобы запустить консольное меню.
4. Выберите уровень и номер задания для запуска.
